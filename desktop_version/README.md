# 손글씨 숫자 인식기 (PyTorch + MNIST)

마우스로 숫자(0~9)를 그리면 합성곱 신경망(CNN)이 어떤 숫자인지 인식하는 프로그램입니다.
MNIST 데이터셋으로 학습하며, 학습된 가중치는 `mnist_cnn.pt` 파일로 저장됩니다.

## 주요 기능

- MNIST 데이터셋 자동 다운로드 및 CNN 학습
- 학습된 가중치를 `mnist_cnn.pt` 로 저장
- tkinter 그림판에 숫자를 그리면 즉시 인식
- 인식 결과, 확신도, 숫자별 확률 막대 그래프 표시

## 파일 구성

| 파일 | 설명 |
|---|---|
| `model.py` | CNN 모델 정의 (학습 코드와 앱이 함께 사용) |
| `train.py` | MNIST로 모델을 학습하고 `mnist_cnn.pt` 로 저장 |
| `app.py` | 손글씨를 입력받아 인식하는 그림판 앱 |
| `make_shortcut.py` | 아이콘(`app.ico`)과 바탕 화면 바로가기를 만드는 코드 |
| `export_web_weights.py` | 가중치를 웹 버전용 `../web_version/weights.js` 로 내보내는 코드 |
| `app.ico` | 앱 아이콘 (`make_shortcut.py` 실행 시 생성) |
| `mnist_cnn.pt` | 학습된 가중치 파일 (`train.py` 실행 시 생성) |
| `data/` | 내려받은 MNIST 데이터 (`train.py` 실행 시 생성) |
| `.venv/` | 이 프로젝트 전용 Python 가상환경 |

## 설치

> 아래 명령은 모두 `desktop_version/` 폴더에서 실행합니다 (`cd desktop_version`).

Python 3.10 이상이 필요합니다. (개발 환경: Python 3.13, PyTorch 2.14 CPU 버전)

```bash
# 1. 가상환경 만들기
python -m venv .venv

# 2. PyTorch (CPU 버전) 설치
.venv/Scripts/python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 3. 이미지 처리 라이브러리 설치
.venv/Scripts/python -m pip install pillow
```

> NVIDIA GPU가 있다면 [PyTorch 공식 사이트](https://pytorch.org/get-started/locally/)에서 CUDA 버전을 설치하면 학습이 훨씬 빨라집니다. `train.py` 는 GPU가 있으면 자동으로 사용합니다.

## 사용 방법

> 아래 명령은 모두 `desktop_version/` 폴더에서 실행합니다 (`cd desktop_version`).

### 1. 모델 학습

```bash
.venv/Scripts/python train.py
```

- 처음 실행하면 MNIST 데이터를 `data/` 폴더에 내려받습니다.
- 5 에폭 학습하며, CPU 기준 에폭당 약 1분 45초가 걸립니다.
- 학습이 끝나면 `mnist_cnn.pt` 파일이 만들어집니다.

실행 예시:

```

[1/5] 손실: 0.5084 | 시험 정확도: 98.36% | 소요 시간: 104.8초
[2/5] 손실: 0.2384 | 시험 정확도: 98.59% | 소요 시간: 107.0초
[3/5] 손실: 0.1914 | 시험 정확도: 98.83% | 소요 시간: 106.8초
```

### 2. 손글씨 인식 앱 실행

```bash
.venv/Scripts/python app.py
```

- 검은 그림판에 마우스로 숫자를 그립니다.
- 마우스 버튼을 떼면 자동으로 인식합니다.
- 오른쪽에 인식된 숫자, 확신도, 0~9 각 숫자의 확률이 표시됩니다.

| 조작 | 동작 |
|---|---|
| 마우스 왼쪽 버튼 드래그 | 숫자 그리기 |
| `인식하기` 버튼 / `Enter` | 다시 인식 |
| `지우기` 버튼 / `Esc` / `Delete` | 그림판 지우기 |

> `mnist_cnn.pt` 파일이 없으면 앱이 실행되지 않으니, 먼저 `train.py` 를 실행해 주세요.

### 3. 바탕 화면 바로가기 만들기 (윈도우)

```bash
.venv/Scripts/python make_shortcut.py
```

- 아이콘 파일 `app.ico` 를 만들고, 바탕 화면에 **손글씨 숫자 인식기** 바로가기를 생성합니다.
- 바로가기는 `pythonw.exe` 로 실행하므로 **검은 콘솔 창 없이 앱 창만** 뜹니다.
- **작업 표시줄에 고정하기**: 바로가기를 마우스 오른쪽 버튼으로 클릭 → `더 많은 옵션 표시` → `작업 표시줄에 고정`
  (또는 앱을 실행한 뒤 작업 표시줄의 아이콘을 오른쪽 클릭 → `작업 표시줄에 고정`)
- 앱과 바로가기에 같은 고유 앱 ID(`DSMP.HandwritingDigitRecognizer`)를 넣었기 때문에,
  고정한 아이콘과 실행 중인 창이 작업 표시줄에서 하나의 버튼으로 합쳐집니다.
- 프로젝트 폴더를 옮겼다면 `make_shortcut.py` 를 다시 실행해 바로가기를 새로 만들어 주세요.

### 4. 웹 버전으로 가중치 내보내기

```bash
.venv/Scripts/python export_web_weights.py
```

- 학습된 가중치를 `../web_version/weights.js` 로, 웹 버전 테스트용 기준값을 `../web_version/tests/reference.js` 로 저장합니다.
- 모델을 다시 학습했다면 이 명령도 다시 실행해야 웹 버전에 반영됩니다.

## 모델 구조

```
입력 (1 x 28 x 28)
 → 합성곱(32채널, 3x3) → 배치정규화 → ReLU → 최대풀링   ⇒ 32 x 14 x 14
 → 합성곱(64채널, 3x3) → 배치정규화 → ReLU → 최대풀링   ⇒ 64 x 7 x 7
 → 드롭아웃(0.25) → 펼치기
 → 완전연결(3136 → 128) → ReLU → 드롭아웃(0.5)
 → 완전연결(128 → 10)                                   ⇒ 0~9 점수
```

### 학습 설정

| 항목 | 값 |
|---|---|
| 에폭 수 | 5 |
| 배치 크기 | 128 |
| 최적화 기법 | Adam (학습률 0.001) |
| 학습률 조정 | 에폭마다 0.7배 감소 (StepLR) |
| 손실 함수 | 교차 엔트로피 |
| 데이터 증강 | 회전 ±10°, 이동 ±10%, 크기 0.9~1.1배 |

데이터 증강은 사람이 직접 그린 삐뚤어진 글씨에도 잘 동작하도록 넣었습니다.

## 인식 정확도를 높이는 전처리

그림판 이미지를 그대로 28x28로 줄이면 MNIST 데이터와 모양이 달라 인식률이 떨어집니다.
그래서 `app.py` 는 MNIST가 만들어진 방식과 똑같이 이미지를 변환합니다.

1. 글씨가 있는 부분만 잘라냅니다.
2. 가로세로 비율을 유지하며 긴 쪽을 20픽셀로 줄입니다.
3. 28x28 검은 배경의 가운데에 붙입니다.
4. 글씨의 무게중심이 정중앙(14, 14)에 오도록 위치를 보정합니다.
5. 학습 때와 같은 평균(0.1307)과 표준편차(0.3081)로 정규화합니다.

## 인식이 잘 안 될 때

- 그림판을 꽉 채우도록 크고 또렷하게 써 보세요.
- 숫자 하나만 그려 주세요. 여러 숫자를 한 번에 인식하지는 못합니다.
- 1과 7, 4와 9처럼 헷갈리기 쉬운 숫자는 특징을 분명하게 그려 주세요.
